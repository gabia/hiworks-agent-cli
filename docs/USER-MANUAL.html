설치 및 명령어

1. 설치

macOS 또는 Linux에서 Git, Node.js 22.19.0 이상, npm, jq를 준비합니다. GitHub 저장소의 소스를 복제한 뒤 저장소 폴더에서 설치합니다.

git clone https://github.com/gabia/hiworks-agent-cli.git
cd hiworks-agent-cli
sh ./install.sh --install
export PATH="$HOME/.local/bin:$PATH"
hac version

설치 완료와 상태 확인 출력 예시 (macOS)

새 터미널에서도 사용하려면 PATH 설정을 셸 설정 파일(예: ~/.zshrc)에 추가해 주세요.

이미 소스를 받은 경우

해당 GitHub 저장소를 복제한 폴더에서 최신 소스를 받고 다시 설치합니다. 작업 중인 로컬 변경을 먼저 확인하고, 갱신에 실패하면 변경을 보존한 상태에서 원인을 확인합니다.

git pull --ff-only
sh ./install.sh --install
export PATH="$HOME/.local/bin:$PATH"
hac version

Git 없이 설치하려면 GitHub의 Code → Download ZIP으로 내려받아 압축을 풀고 install.sh가 있는 폴더에서 설치 명령을 실행합니다. ZIP 설치본은 새 소스를 내려받아 갱신합니다.

AI 에이전트에게 설치 요청

터미널을 실행할 수 있는 AI 에이전트에게 아래 내용을 전달합니다. 에이전트가 저장소를 복제하고 루트의 README.md를 읽어 설치하도록 요청하는 예시입니다.

https://github.com/gabia/hiworks-agent-cli 저장소를 복제하고 README.md를 읽어, 이 컴퓨터에 Hiworks Agent CLI(hac)를 설치해 주십시오.
지원 환경과 Git·Node.js·npm·jq를 확인한 뒤 저장소 루트에서 sh ./install.sh --install을 실행해 주십시오.
현재 셸과 셸 설정 파일에 PATH를 중복 없이 등록하고, hac version과 hac doctor 결과를 확인해 주십시오.
기존 저장소나 작업을 덮어쓰지 마십시오.
인증 값이 없다면 설치를 먼저 완료하고 hac setup 방법을 안내해 주십시오. API Key는 로그나 명령행 인자에 노출하지 마십시오.

상세 절차와 비대화형 AI Hub 연결 방법은 사용자 매뉴얼에 있습니다. 기존 복제본을 사용할 때는 원격 주소와 로컬 변경을 확인하고 git pull --ff-only로 갱신합니다.

hac 화면의 입력란에서 /model로 사용할 모델을 선택한 뒤 작업을 요청합니다. AI Hub는 hac setup에서 기본 모델을 선택할 수 있습니다.

첫 실행 화면 예시

명령어

대화 화면에서는 /로 시작하는 명령을 입력합니다. /만 입력하면 현재 사용 가능한 명령이 표시됩니다.

hac 실행 화면에서 · 슬래시 명령

/login Codex 연결  ·  /model 모델 선택
/usage 현재 모델 사용현황  ·  /settings 일반 설정
/resume 저장된 대화 선택  ·  /new 새 대화
/session 현재 대화 정보  ·  /quit 종료

일반 터미널에서 · hac 명령

hac 실행  ·  hac setup AI Hub 연결
hac --continue 현재 폴더의 최근 대화 이어가기
hac usage 연결된 AI Hub·Codex 사용현황 모두 보기
hac doctor 상태 점검  ·  hac version 버전 확인
hac install 설치  ·  hac install --repair 복구
hac update hac(배포처 설정 시)·Pi 업데이트  ·  hac pi update Pi 업데이트
hac pi list 패키지 목록  ·  hac pi config 리소스 설정
hac pi install npm:패키지명 추가  ·  hac pi remove npm:패키지명 제거
hac uninstall 제거  ·  hac --help 전체 도움말

/usage는 현재 모델의 AI Hub·Codex 사용현황을, hac usage는 연결된 두 서비스의 사용현황을 보여 줍니다. /resume은 대화를 고르고, hac --continue는 최근 대화를 바로 엽니다. 설치·업데이트·진단·제거는 터미널에서 실행합니다.

문제 해결 · hac doctor로 상태를 확인합니다. 실행 파일이 손상되었다면 hac install --repair로 복구할 수 있습니다.
