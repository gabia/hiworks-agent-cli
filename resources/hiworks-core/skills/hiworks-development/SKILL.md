# Hiworks Development

Use the repository's existing conventions before introducing new abstractions.
Make the smallest safe change, keep credentials and user settings out of release
resources, and validate behavior with focused tests before declaring completion.

This skill is guidance only. It does not provide sub-agent orchestration or
access to external systems.
